# Origem dos dados

- Autor: Paulo Cortez.
- Base: Student Performance, UCI Machine Learning Repository (2008).
- DOI: https://doi.org/10.24432/C5TG7T
- Página: https://archive.ics.uci.edu/dataset/320/student-performance
- Download: https://archive.ics.uci.edu/static/public/320/student+performance.zip
- Arquivo usado: student-por.csv, 649 linhas de dados e 33 colunas, separador ponto e vírgula.
- Dicionário: student.txt, preservado como fornecido.
- Licença informada pelo repositório: CC BY 4.0. Crédito mantido neste arquivo e no relatório.
- Acesso: 16/11/2026.
- SHA-256 do CSV: a7594a11d7771c0efe1a740824e0e833da9c4cad07c39a9766a874575563fb3f

A base de Português foi usada sozinha. Os dados de Matemática não foram combinados, evitando misturar estudantes que aparecem em ambas as disciplinas. O arquivo original não foi editado. Os índices dos conjuntos discretizados são os índices de linha do pandas, a partir de zero.

A aprovação prévia desta base pelos professores ainda precisa ser confirmada pelo grupo.
